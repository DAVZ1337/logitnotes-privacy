Política de privacidad de LogitNotes

Última actualización: 25 de octubre de 2026

1. Información general

LogitNotes es una aplicación Android para crear, editar y organizar notas. Esta política explica cómo se trata la información al utilizar la aplicación.

2. Datos y almacenamiento

Según el funcionamiento previsto de la aplicación, las notas y los datos que el usuario introduce se almacenan localmente en su dispositivo. La aplicación no utiliza servidores propios para sincronizar las notas ni servicios de publicidad o analítica.

Los datos almacenados localmente pueden permanecer en el dispositivo hasta que el usuario los elimine mediante las funciones disponibles o elimine los datos de la aplicación. Las copias de seguridad del dispositivo o las funciones del sistema operativo pueden tener sus propias condiciones.

3. Desbloqueo biométrico

Si el usuario activa el desbloqueo biométrico, la verificación la gestiona el sistema Android y los mecanismos biométricos del dispositivo. LogitNotes no recibe ni almacena imágenes de huellas dactilares ni datos biométricos en bruto.

4. Recopilación y comunicación de datos

La aplicación no está diseñada para enviar notas ni datos personales a servidores propios, anunciantes o proveedores de analítica. Esta declaración debe revisarse si se incorporan bibliotecas o servicios que transmitan datos.

5. Seguridad

Se recomienda mantener actualizado Android y proteger el dispositivo mediante un método de bloqueo seguro. La protección efectiva de los datos también depende de la implementación y configuración de la aplicación y del dispositivo.

6. Conservación y eliminación

Los datos locales se conservan mientras permanezcan almacenados en el dispositivo. El usuario puede eliminarlos utilizando las opciones disponibles en la aplicación o en los ajustes de Android. La recuperación de datos eliminados puede no ser posible.

7. Privacidad de menores

LogitNotes no solicita datos personales para crear una cuenta. Los usuarios deben utilizar la aplicación de acuerdo con las condiciones aplicables a su edad.

8. Cambios en esta política

Esta política podrá actualizarse cuando cambien las funciones o las prácticas de tratamiento de datos. La versión vigente estará disponible en esta página.
